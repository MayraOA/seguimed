# Entrevista 05 — Médico independiente (Cirujano)
**Fecha:** Junio 2026
**Perfil:** Médico independiente, especialidad quirúrgica, Lima
**Canal:** WhatsApp / Presencial
**Duración:** ~15 min

## Respuestas

| Pregunta | Respuesta |
|---|---|
| Canales de contacto | WhatsApp + Instagram + llamadas |
| Mensajes sin responder/semana | Ninguno — siempre responde todos |
| Cómo hace seguimiento | Guarda nombre + procedimiento en el contacto del celular |
| ¿Ha perdido pacientes por falta de seguimiento? | Hace seguimiento proactivo a los que no concretan cirugía |
| Sistema para fechas importantes | No tiene ninguno |
| Tiempo semanal gestionando mensajes | ~1 hora |
| Disposición a pagar | **S/.50/mes** |

## Hallazgos clave

- Primer entrevistado en dar un precio concreto: **S/.50/mes** — valida directamente el Plan Básico de SeguiMed (S/.49/mes)
- Ya hace seguimiento proactivo manual a pacientes no convertidos — confirma que el comportamiento existe, pero sin herramienta que lo escale
- Usa Instagram además de WhatsApp — potencial de integración multi-canal en versión futura
- Su sistema actual (nombre + procedimiento en el contacto) es el más "estructurado" pero totalmente manual y no escalable

## Cita textual destacada

> "Suelo hacer seguimiento a los que no concreto una cirugía."

## Insight para el pitch

Este médico ya tiene el comportamiento correcto — hace seguimiento proactivo. SeguiMed no cambia su mentalidad, solo escala lo que ya hace: en lugar de revisar uno por uno sus contactos manualmente, el dashboard le muestra automáticamente a quién contactar y la IA genera el mensaje.

## Validación de precio

S/.50/mes mencionado espontáneamente = validación directa del Plan Básico (S/.49/mes). Ningún otro entrevistado dio número — este fue el único que lo hizo sin que se le sugiriera monto.
