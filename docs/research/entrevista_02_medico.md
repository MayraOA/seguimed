# Entrevista 02 — Médico independiente
**Fecha:** Junio 2026
**Perfil:** Médico independiente, Lima
**Canal:** WhatsApp / Llamada
**Duración:** ~15 min

## Respuestas

| Pregunta | Respuesta |
|---|---|
| Canales de contacto | WhatsApp + llamadas |
| Mensajes sin responder/semana | Ninguno |
| Cómo hace seguimiento | Solo cuando el paciente llama o viene a la cita (reactivo) |
| ¿Ha perdido pacientes por falta de seguimiento? | **Sí, varios** |
| Sistema para fechas importantes | No |
| Tiempo semanal gestionando mensajes | Ninguno (no dedica tiempo activo) |
| Disposición a pagar | Dependería de la cantidad de pacientes |

## Hallazgos clave

- Confirma el dolor central: pierde pacientes de forma recurrente ("varios")
- El seguimiento es 100% reactivo — solo actúa cuando el paciente da el primer paso
- No tiene ningún sistema de seguimiento proactivo ni recordatorios
- La disposición a pagar está ligada al volumen de pacientes — validación del modelo escalonado (Básico / Pro / Clínica)

## Cita textual destacada

> "Lo realizo cuando me llaman o vienen a la cita."

## Insight para el pitch

Este es el perfil más común: el médico que responde bien pero nunca inicia el contacto. Sus pacientes se pierden en silencio porque nadie los busca. SeguiMed invierte la ecuación.
